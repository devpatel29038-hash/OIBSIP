# BMI Calculator

## Internship
Oasis Infobyte - Python Programming Internship

## Project
BMI Calculator (Beginner Tier)

## Objective
To calculate Body Mass Index (BMI) using
the user's weight and height.

## Features
- Takes weight in kilograms.
- Takes height in meters.
- Calculates BMI.
- Displays BMI category.
- Handles invalid numeric inputs.
- Rejects zero and negative values.

## Formula
BMI = Weight (kg) / Height (m)²

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Open the project folder.
3. Run the command:

 python bmi_calculator.py

## Output
Displays BMI value and category.
